# SMART MENTOR

AI негізіндегі жеке ментор жүйесі — жатақхана жағдайында оқушыларды информатика
олимпиадасына жүйелі дайындауға арналған мобильді қосымша.

AI-система персональной подготовки к олимпиаде по информатике для учеников,
живущих в интернате.

## Не істейді / Что делает

- Оқушының күн тәртібін талдап, бос уақытын автоматты есептейді
- Бос уақытқа қарай жеке оқу жоспарын құрады
- Күн сайын жеке тапсырмалар генерациялайды (Easy / Medium / Hard)
- Тапсырмада нақты есеп шарты, кіріс-шығыс мысалдары, кеңес және талдау болады
- Тақырып бойынша мини-тест өткізеді, нәтижені өзі прогреске жазады
- Әр тақырыпқа қысқа конспект береді: негізгі идея, тармақтар, жиі кететін қате
- Прогресті бақылап, әлсіз тақырыптарды анықтайды
- Әлсіз тақырыпты қайталау аралығы бойынша жоспарға қайтарады
- Нәтижеге қарай тапсырма күрделілігін бейімдейді
- AI Mentor чаты арқылы кеңес береді
- Еске салғыштар жібереді
- Интернетсіз де жұмыс істейді: деректер құрылғыда сақталады

## Технологиялар

- Flutter / Dart
- Provider — күй басқару
- Firebase Auth және Cloud Firestore — тіркелу мен деректер
- SharedPreferences — құрылғыдағы кэш, желісіз жұмыс үшін
- Gemini API — жоспар, тапсырма шарты мен тест сұрақтарын генерациялау
- fl_chart — графиктер
- Қазақша және орысша интерфейс (ауыстырғыш параметрлерде)
- Ашық және қараңғы тема

## Жобаның құрылымы

```
lib/
├── core/          тема, түстер, локализация, уақытпен жұмыс
├── data/
│   ├── models/    User, Task, ScheduleItem, TestResult, ChatMessage
│   ├── local/     құрылғыдағы кэш және баптаулар
│   ├── remote/    Firestore қабаты
│   ├── repositories/  дерекке қол жеткізу қабаты
│   ├── reports/   мәтіндік есеп
│   └── ai/        тақырыптар каталогы, бос уақыт есептегіші, жоспар генераторы,
│                  сұрақтар банкі, есеп шарттары, конспекттер, қайталау жоспарлағышы
├── state/         AppState, SettingsState
├── widgets/       ортақ UI компоненттері
└── features/      экрандар
```

## AI алгоритмі

1. Күн тәртібінен бос уақыт терезелері есептеледі
2. Қайталау мерзімі жеткен тақырыптар алдыға шығады: нәтижесі нашары 3 күнде,
   орташасы 7 күнде, меңгерілгені 21 күнде оралады
3. Соңғы 7 күндегі нәтиже мен оқушының қарқыны бойынша күрделілік бейімделеді
4. Тапсырмалар бос уақыт терезелеріне орналастырылады
5. Орындалған тапсырмалар мен тест нәтижелері прогреске және келесі жоспарға әсер етеді

AI қолжетімсіз болса, жоспарды кіріктірілген алгоритм құрады — қосымша
интернетсіз де толық жұмыс істейді.

AI жауабын талдау және қайталау жоспарлағышы тестпен жабылған.
